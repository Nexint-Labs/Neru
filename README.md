# MikuBot

The source code for NeruBot. Updated occasionally.

## Features:
- Moderation
- Gif commands
- Other neat little tid-bits

# Pre-requisites:
- Nodejs and npm are required
- Stable internet connection is required

## How to install?
- Download the files off the repository
- Set them into a seperate folder
- Download and install NPM and NodeJS
- Run "npm install" inside of this folder using the Command Prompt
- If there are any vulnerabilities that need fixing, run "npm audit fix"
- Make a Discord Bot using discord.dev
- Config the config.js file
- Run the start.bat file, or if you're on linux, run the command "node index.js"

## FAQ:
"Error: Used Disallowed Intents"
- Enable all 3 privileged intents

## Notes:
- Guild ID is optional
- Client ID is the application ID
- Tenor key is outdated
- Klipy key requires an API key from the Klipy API. If this doesn't exist, the bot will still work, but any gif commands will result in errors.
